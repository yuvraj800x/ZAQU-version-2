# ZAQU-version-2
Zaqu is an AI-powered voice assistant built with Python.  It supports both voice and text input, understands Hindi  and English, opens websites and Windows apps by voice,  and uses Llama 3.2 AI model (via Ollama) for intelligent  offline responses — just like a personal Jarvis! 🤖🎤
## Features
🎤 Voice + Typing both modes
🌐 Opens websites by voice (YouTube, Google, Instagram...)
💻 Opens Windows & MS Office apps by voice
🇮🇳 Hindi + English + Hinglish support
🤖 Powered by Llama 3.2 AI (Offline)
⏸️ Pause/Resume feature
🔊 Text to Speech response

## Tech Stack
- Python
- SpeechRecognition
- Ollama (Llama 3.2)
- pyttsx3
- OpenCV (coming soon)

## How to Run
1. Install Ollama
2. Run: ollama pull llama3.2:3b
3. pip install speechrecognition pyttsx3 ollama keyboard
4. python speech_recognition4.py
